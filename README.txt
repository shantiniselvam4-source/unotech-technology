UNOTECH TECHNOLOGY WEBSITE UPDATE

Files: index.html, about.html, services.html, contact.html, style.css

Copy these five files into C:\Unotech-Website, replacing the existing index.html and style.css and adding the three new HTML pages. Keep your existing images folder unchanged.

Then preview index.html in your browser. If everything looks right, in the VS Code terminal run:
  git add .
  git commit -m "Refresh black and white website and add separate pages"
  git push

The navigation now opens separate pages: Home, About Us, Our Services, Contact.
